1. Get the application URL by running these commands:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ $.Values.ingress.path }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "sccsos.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.service.type }}
  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
  You can watch the status by running:
  kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "sccsos.fullname" . }}
{{- else }}
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "sccsos.fullname" . }} 8765:8765
{{- end }}

2. Verify the deployment:
  curl http://localhost:8765/api/v1/health

3. **Post-install setup** (first time only):
  kubectl exec --namespace {{ .Release.Namespace }} deploy/{{ include "sccsos.fullname" . }} -- sccsos init
  kubectl exec --namespace {{ .Release.Namespace }} deploy/{{ include "sccsos.fullname" . }} -- sccsos agent create architect

4. **Scaling**:
  The HPA is configured with {{ .Values.autoscaling.minReplicas }}-{{ .Values.autoscaling.maxReplicas }} replicas.
  To manually scale: kubectl scale --namespace {{ .Release.Namespace }} deploy/{{ include "sccsos.fullname" . }} --replicas=3
