# ADR：SCCS OS 架构进化 v0.14.3→v0.15.5 间隙覆盖

- **日期**: 2026-07-25
- **状态**: 已接受
- **版本关联**: v0.14.3 ~ v0.15.5（内部补丁版本）
- **前置 ADR**: ADR-014（v0.9→v0.14.2）、ADR-022（v0.15→v0.16.5）

---

## 背景

ADR-014 覆盖 v0.9.0~v0.14.2，ADR-022 覆盖 v0.15.0~v0.16.5。中间 v0.14.3~v0.15.5 均为**内部补丁与架构审计**版本，无独立架构级决策，但涉及架构审计、健康评分修正、代码死区清理、版本号全文件同步等重要基操。

---

## 版本覆盖

| 版本 | 核心内容 | 架构影响 |
|------|---------|---------|
| **v0.14.3** | 技能评分 bug 修复 | 无 |
| **v0.14.4** | API 路由优化 | 无 |
| **v0.14.5** | 安全审计补充 | 无 |
| **v0.15.0** | **架构审计启动** — 7 域 × 6 维度健康评分，健康评分 9.2→8.7 修正 | 🔴 评分下调但质量提升 |
| **v0.15.1** | AgentMessageBus 标记 Deprecated（228 行零引用） | 🟡 代码清理 |
| **v0.15.2** | 版本号全文件同步机制建立 | 🟢 工程规范 |
| **v0.15.3** | 测试覆盖率基线建立（fail-under） | 🟢 工程规范 |
| **v0.15.4** | CI 门禁规范化 | 🟢 工程规范 |
| **v0.15.5** | 预发布收尾 | 无 |

---

## 决策总结

1. **健康评分真实化**：主动将评分从 9.2 下调至 8.7，暴露 5 个 Major + 6 个 Minor 问题
2. **版本同步工程化**：版本号从 20 文件扩展到 46 文件同步脚本化（`grep -r "version.*=" src/` → 全量扫描）
3. **死代码零容忍**：标注 Deprecated 的 `AgentMessageBus` 在下一大版本移除
4. **架构审计制度化**：每个大版本发布前执行 7 域审计

> 所有架构决策已在 ADR-014 和 ADR-022 中详细记录。本 ADR 仅做间隙覆盖，无新增架构决策。
